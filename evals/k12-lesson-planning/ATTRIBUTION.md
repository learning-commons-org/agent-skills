# Attribution

The K-12 lesson-planning evaluation in this folder was **co-developed by
[Learning Commons](https://learningcommons.org/) and
[Anthropic](https://www.anthropic.com/)** as part of a shared commitment to
transparent, field-grounded quality standards for AI in K-12 education.

## Scope

This evaluation currently ships as a **rubric only** — the criteria in
[`rubrics/`](rubrics/) that define what a strong, standards-aligned lesson-plan
output looks like (see the repository [`evals/README.md`](../README.md) for how
to apply them, including as an LLM-as-judge). It is an early piece of a larger
evaluation harness that Learning Commons and Anthropic plan to publish in full
at a later date. Until then, manual reproduction instructions are provided.

The rubric criteria were refined with input from education practitioners and
researchers, and remain a living framework we intend to revise as the field
learns more. Feedback is welcome — see the repository README for how to reach us.
